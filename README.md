# Limitless Finance

## Project Overview

Limitless Finance is a beginner-friendly budgeting application I built to practice and improve my web development skills. The app helps users keep track of their income, expenses, monthly balance, and personal savings goals.

I wanted to create something useful while also challenging myself to learn more about HTML, CSS, and JavaScript. I chose a Gojo-inspired theme with blue and purple colors to give the application its own style.

## Features

- **Budget Dashboard:** Displays total balance, income, and expenses.
- **Transaction Tracking:** Add income and expenses with descriptions and amounts.
- **Transaction Filters:** View all transactions, income only, or expenses only.
- **Clear Transactions:** Remove all saved transactions.
- **Savings Goal Tracker:** Enter an amount saved and a savings target to calculate progress.
- **Data Persistence:** Uses browser localStorage to save transactions and savings information after refreshing the page.
- **Custom Design:** Gojo-inspired blue and purple theme with glass-style panels and glowing effects.

## Technologies Used

- HTML5 – Builds the structure of the application.
- CSS3 – Handles the layout, colors, backgrounds, and visual effects.
- JavaScript – Handles calculations, transactions, filters, and savings progress.
- Browser localStorage – Saves application data in the browser.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Start adding income, expenses, and savings goals.
